# TalkSimul · 작은 회화 아지트

한국어 사용자를 위한 영어·일본어 회화 연습 웹 앱입니다. 주황·크림·브라운의 작은 공간에서 오리지널 대화 친구 **모루**와 연습하고, 실제로 남긴 문장을 다시 살펴봅니다.

**현재 상태: Vercel 운영 주소에서 영어·일본어 음성 대화 전체 흐름을 검증했습니다.** 합성 음성을 WebRTC로 보내 전사·AI 응답·힌트·발음 재생·복기·종료 정리를 확인했고, 390px 복기 화면과 새로고침 후 기록 보존도 확인했습니다. 사람의 실제 마이크와 스피커 청취는 검증하지 않았습니다. 고정 데모 응답을 실제 AI 연결로 표시하지 않으며, 자세한 결과와 한계는 [검증 기록](docs/VERIFICATION.md)에 남깁니다.

## 로컬 개발 실행하기

Node.js 22.12 이상과 npm이 필요합니다. 개발 환경에서는 Node.js 24.12.0, npm 11.6.2를 사용했습니다.

```powershell
cd C:\Users\nonam\Documents\TalkSimul
npm.cmd ci
npm.cmd run dev
```

[TalkSimul 열기 · http://127.0.0.1:5188](http://127.0.0.1:5188)

- 프론트엔드: `127.0.0.1:5188`, 로컬 API 서버: `127.0.0.1:3001`
- 다른 프로그램을 종료하거나 포트를 강제로 빼앗지 않습니다. 포트가 사용 중이면 이 앱의 이전 실행 터미널을 먼저 종료하세요.
- Windows PowerShell의 스크립트 실행 정책 때문에 `npm`이 차단되면 위처럼 `npm.cmd`를 사용하세요. 시스템 실행 정책을 바꿀 필요는 없습니다.
- 종료: 실행 중인 터미널에서 `Ctrl+C`.
- 휴대폰 크기는 브라우저 기기 에뮬레이션으로 확인했습니다. 로컬 개발 서버는 **현재 PC의 loopback 전용**입니다. 서버에서 사용하려면 위 Vercel 주소로 접속하세요.

빌드된 앱을 로컬에서 실행하려면:

```powershell
npm.cmd run build
npm.cmd start
```

이때 화면 주소는 [http://127.0.0.1:3001](http://127.0.0.1:3001)입니다. 브라우저 저장소는 **포트별로 분리**되므로 5188에서 만든 기록이 3001에 나타나지 않는 것은 정상입니다.

## 사용 흐름

1. 홈에서 영어 또는 일본어와 입문·기본·도전 난이도를 고릅니다.
2. 자유 대화를 시작하거나 카페·호텔·친구·길 묻기 상황을 고릅니다.
3. 준비 화면에서 설정과 대화 방식을 확인합니다.
4. 대화 중 `뭐라고 말하지?`로 현재 맥락의 표현과 한국어 의미를 봅니다. 힌트는 내 발화에 자동 추가되지 않습니다.
5. `대화 마치기`로 복기를 열고, 직접 남긴 문장과 개선 표현을 확인합니다.
6. 같은 설정으로 다시 연습하거나, 이 기기의 기록에서 이전 복기를 엽니다. 기록 삭제는 확인 후 선택한 세션만 삭제합니다.

### 데모와 실제 모드

|                 | 데모                                           | 실시간 AI                                                  |
| --------------- | ---------------------------------------------- | ---------------------------------------------------------- |
| 입력            | 직접 텍스트 입력                               | 마이크 음성 또는 직접 텍스트                               |
| 응답            | 상황별 고정 예시, 일부 키워드 분기             | OpenAI Realtime의 실제 응답                                |
| 힌트            | 현재 질문에 맞춘 준비된 예시                   | 대화 맥락을 전달한 AI 생성                                 |
| 복기            | 실제 입력 문장 + 명시된 두 가지 예시 교정 규칙 | 실제 전사·입력 문장에 근거한 AI 교정                       |
| 평가            | `AI 평가 안 함`, `음성 평가 안 함`             | 전사 텍스트의 전달력·자연스러움·문법·어휘에 대한 짧은 설명 |
| 마이크/외부 API | 사용 안 함                                     | 시작 전 설정과 동의 필요                                   |

데모의 교정 규칙은 영어 `I goed` → `I went`, 일본어 `昨日 … 行きます` → `昨日 … 行きました`입니다. 다른 문장을 AI가 평가한 것처럼 설명하지 않습니다. `연습할 예문 넣기`는 입력란만 채우며, 보내기를 눌러야 발화가 됩니다.

## 실제 AI 연결 설정 — 키를 채팅에 보내지 마세요

1. 프로젝트 안의 `.env.example`을 `.env`로 복사합니다. 기존 `.env`가 있다면 덮어쓰지 마세요.
2. **로컬 `.env` 편집기 안에서만** `OPENAI_API_KEY`를 입력합니다. `VITE_`로 시작하는 변수에 키를 넣지 마세요.
3. API 비용과 OpenAI로의 음성·대화 전송을 승인할 때만 다음 설정을 바꿉니다.

```dotenv
TALK_SIMUL_ENABLE_PAID_API=true
```

4. 로컬 서버를 다시 시작하고 앱 오른쪽 위 설정에서 `설정 상태 다시 확인`을 누릅니다.
5. 준비 화면의 `실시간 AI 음성 대화`를 선택하고 음성·대화 전송 및 비용 동의를 체크합니다.
6. `마이크 켜고 대화 시작`을 직접 누른 뒤 브라우저 마이크 권한을 허용합니다.

키가 설정되어도 비용 허용 플래그가 `false`이면 외부 AI 호출을 하지 않습니다. 상태 표시의 “준비됨”은 로컬 설정 확인이며, 계정의 모델 권한이나 실제 연결 성공을 뜻하지 않습니다. 모델 접근 가능 여부와 결제·사용량 한도는 계정에서 확인해야 합니다.

기본 모델은 `gpt-realtime-2.1`(회화), `gpt-6-luna`(힌트·복기), `gpt-4o-mini-transcribe`(발화 전사)입니다. 공식 문서 확인일은 2026-10-09입니다. 힌트·복기는 Responses API와 `reasoning.effort: low`를 사용합니다. GPT-6 Luna는 오디오를 지원하지 않으므로 회화·전사·TTS는 각 음성 모델을 사용합니다. [API 선택 근거와 계약](server/API-NOTES.md)을 참고하세요.

기존 `.env`나 Vercel 환경변수에 `OPENAI_TEXT_MODEL`을 설정했다면 코드의 기본값보다 우선합니다. GPT-6 Luna를 쓰려면 해당 값을 `gpt-6-luna`로 변경한 뒤 로컬 서버를 다시 시작하거나 Vercel에 다시 배포하세요.

### 데이터와 음성

- 일반 API 키는 서버에서만 읽습니다. Vercel에서는 서버 전용 민감 환경변수, 로컬 개발에서는 `.env`를 사용합니다. 프론트엔드 번들·브라우저 저장소·로그에 넣지 않습니다. `.env`는 Git 제외 대상입니다.
- 실제 모드에서 음성은 WebRTC로 OpenAI에 전송됩니다. 힌트·복기를 만들 때는 대화 텍스트가 서버를 거쳐 OpenAI로 전송됩니다. Responses 요청에는 `store:false`를 설정합니다. 이는 제공자의 모든 보관 정책을 무효화한다는 뜻은 아닙니다.
- 원본 음성 파일을 앱에서 녹음하거나 저장하지 않습니다. 대화 텍스트·복기·설정·시간은 해당 브라우저의 `localStorage`에 저장합니다. 암호화된 보관소나 계정 동기화는 아닙니다.
- 세션 종료·화면 이탈·연결 실패 시 마이크 트랙, 오디오, WebRTC, 데이터 채널, 타이머와 요청을 정리합니다. 종료 시 마이크를 즉시 끄고 최대 1.8초 동안 이미 시작된 전사를 기다립니다. 전사 누락 가능성은 기록에 표시합니다.
- 힌트 화면에서는 마이크와 AI 오디오를 멈춥니다. 힌트 음성을 취소한 뒤 사용자가 선택한 음소거 상태로 돌아갑니다.
- 발음 버튼은 기기 내 영어·일본어 음성(`localService`)을 먼저 사용합니다. **데모는 로컬 음성만** 사용하며, 없거나 실패하면 안내합니다. **실제 모드는 기기 음성 재생이 불가능하면 OpenAI TTS로 해당 문장을 전송**해 AI 음성을 재생합니다. 세션 시작 전과 발음 버튼 근처에 전송·비용을 안내합니다. 생성한 MP3는 재생 중 메모리에만 두고 종료·취소 시 해제합니다. TTS는 `gpt-4o-mini-tts`를 사용하며 2,000자 이하 문장만 받습니다.
- 초기 제한된 실행 환경에서는 영어 기기 음성이 없었고 일본어 기기 음성도 실패했습니다. 이후 승인된 실행 환경의 격리 Edge에서는 일본어 기기 음성의 시작·종료 이벤트가 정상 발생했습니다. 영어는 API 음성의 실제 재생 진행·종료를 확인했습니다. 이는 브라우저 재생 경로의 검증이며 사람의 스피커 청취를 뜻하지 않습니다. 시스템 음성 설치나 설정 변경은 하지 않았습니다.
- 마이크 권한 거절·장치 없음·장치 사용 중·연결 시간 초과·응답 실패를 처리합니다. 실제 모드 실패를 데모 성공으로 바꾸지 않습니다.
- 손상된 저장 데이터는 덮어쓰지 않습니다. 저장 공간 부족·저장 차단 시 실패 안내와 재시도 버튼을 보여 줍니다.

## 검증

```powershell
npm.cmd run typecheck
npm.cmd test
npm.cmd run build
```

브라우저 테스트는 먼저 `npm.cmd run dev`로 앱을 실행한 다음 별도 터미널에서 실행합니다.

```powershell
npm.cmd run test:e2e
```

설치된 Microsoft Edge가 있으면 임시 프로필의 headless Edge를 사용합니다. 사용자 프로필·쿠키를 사용하지 않습니다. 다른 OS에서 Playwright Chromium이 없다면 `npx.cmd playwright install chromium`으로 공식 브라우저 패키지를 설치할 수 있습니다.

위 기본 자동 테스트는 실제 유료 AI 요청을 보내지 않습니다. API 테스트는 가짜 전송 계층을 사용하며, 브라우저 테스트는 외부 요청과 AI POST를 차단합니다. 별도 승인 후에만 실행하는 실제 음성 검사는 [실제 연결 검사 안내](tests/live/README.md)에 있습니다. 결과·남은 수동 검증·스크린샷은 [검증 기록](docs/VERIFICATION.md)에 정리합니다.

- 공개 레퍼런스 링크, 이미지 생성 프롬프트, 셀 좌표: [디자인 출처 문서](docs/DESIGN-SOURCES.md).

## 검증 범위와 한계

사용자 승인 후 Vercel 운영 주소에서 영어·일본어의 전체 음성 흐름을 검증했습니다. 검사는 격리된 Edge에 합성 음성 스트림을 넣는 방식으로 진행했고, 사용자의 개인 음성은 캡처하지 않았습니다. 직접 연습할 때는 위 운영 주소를 열고, 실제 마이크 권한과 스피커 출력을 확인하세요. 모델 피드백은 오판할 수 있어 원문을 함께 표시합니다. 실제 청구 금액은 조회하지 않았습니다.

실제 스마트폰 하드웨어, Safari/Firefox, 네트워크 전환 환경은 확인하지 않았습니다. 회원가입·결제·랭킹·장기 통계는 MVP 범위에 포함하지 않았습니다. 외부 배포는 추가 요청에 따라 Vercel에서 완료했습니다.
